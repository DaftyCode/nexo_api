{{ 'Databases' | transloco }}

{{ 'Databases holds your PostgreSQL, SQL Server, MySQL, MariaDB and SQLite connections. The first connection of an engine downloads its driver, which is checked before every start; Settings → Modules lists the drivers and installs one from a file.' | transloco }}

  • {{ '+ Connection opens the wizard: paste a URL (JDBC too) or fill in the fields, choose TLS and the connection type (production shows in red), and Test connection.' | transloco }}
  • {{ 'The Network tab of a connection takes it through a SOCKS5 proxy (its password kept in the vault) or the SSH tunnel of a profile of Settings → SSH. Test the tunnel reaches the server through it without signing in; TLS still checks the server by its own name.' | transloco }}
  • {{ 'The Startup tab runs queries in every session as it opens (one statement each; a read-only connection only reads or sets the session), sets PostgreSQL’s default schema, keeps the connection alive with a trivial query, closes it sooner when unused and limits how long it may take to open. A session that closed opens again on its next use: what only reads runs again, what writes never does.' | transloco }}
  • {{ 'A connection can keep no password: Ask for the password each time asks for it when a session opens and keeps it until its sessions close; a PostgreSQL connection can read it from your user’s pgpass file. Nexo never runs a command to get a password.' | transloco }}
  • {{ 'Settings → Connection types adds types of your own besides development, test and production: a name, a color and what every session of their connections does (commit by hand, confirm each change or only changes of structure, only read, a time limit). Nexo applies them to every statement.' | transloco }}
  • {{ 'Navigator options → Import connections… reads the connections of DBeaver (data-sources.json), pgAdmin (servers.json), MySQL Workbench (connections.xml), a list of URLs or a file exported from Nexo, and shows what comes before saving it. No password comes: the connections ask for it. Export connections downloads yours, without secrets.' | transloco }}
  • {{ 'In the navigator, a click expands a row and a double click opens a table on its data. F5 refreshes a node, Shift+F10 opens its actions and Ctrl+H searches objects, data and saved scripts.' | transloco }}
  • {{ 'The Files and DuckDB module opens a folder (each CSV, TSV, JSON, Parquet and Excel file in it is a table named after the file), files separated by ;, or a .duckdb database. Join files with SQL as tables of one database. Nexo only reads these files, without network or extensions; the reader settings (delimiter, header, sheet…) are in Driver settings.' | transloco }}
  • {{ 'Database tasks (▶ in the navigator) save SQL scripts on some connections, a copy of a query into a table of another connection, a comparison of two schemas or tables, a backup or other tasks in order. Run one now or every few minutes or hours while Nexo is open: each run stays in its history, and a failure or a difference found is notified. Nobody confirms a scheduled run, so what would ask (changes in production, statements on every row, DROP) runs only if the task authorizes it.' | transloco }}

{{ 'SQL editor and results' | transloco }}

  • {{ 'Ctrl+Enter runs the statement at the cursor or the selection, Ctrl+\\ runs it in a new result tab and Alt+X runs the whole script. Each tab has its own session.' | transloco }}
  • {{ 'The editor completes from the schema, formats (Ctrl+Shift+F), explains the plan (Ctrl+Shift+E) and asks for the :name parameters before sending them.' | transloco }}
  • {{ 'In the grid, edit cells and save every change together; copy rows as TSV, JSON, CSV, Markdown, IN or INSERT; open the Value, Metadata, Calc and Grouping panels.' | transloco }}
  • {{ 'In manual commit mode, statements wait in a transaction until you commit (Ctrl+Alt+Shift+K) or roll back (Ctrl+Alt+Shift+R).' | transloco }}
  • {{ 'Export results to eight formats, import CSV or JSON, and copy data between connections of different engines.' | transloco }}
  • {{ 'Visual, beside Text in the toolbar of a SQL tab, shows the SELECT at the cursor as tables on a canvas: drag tables from the navigator (or add them from the list), tick their columns, drag a column onto another to join them, and click a join to change its kind. The panels edit columns, conditions, grouping, order, joins and the page; the SQL is written again with every change. A statement with subqueries, UNION, WITH or window functions is only shown, never rewritten.' | transloco }}
  • {{ 'Generate test data… in the menu of a table fills it with made-up rows: a generator for each column, chosen from its type and name (numbers, texts, lists, patterns, names, emails, phones, IBANs, dates, JSON, a key of the table it references), the rows to make and a seed that makes the same rows again. Preview twenty, then write them by batches, or save them as a script of INSERTs or a CSV file. It is not offered on production or read-only connections.' | transloco }}
  • {{ "The Chart view of a result (and the chart button of a table's data) charts the rows loaded: a date gives a time line and a text bars, without setting anything. Choose lines, area, bars, horizontal or stacked bars, a pie or dots, the X column, the series or a series per value of another column, how repeated values add up, the order and the categories shown. The legend hides series; Show as a table has the same numbers; SVG, PNG and Print export it. The chart is kept with the saved script." | transloco }}
  • {{ 'A result with geometries (PostGIS, MySQL, MariaDB, SQL Server) shows them as WKT in its cells and has a Spatial view: every geometry drawn on a canvas, zoomed with the wheel and moved by dragging, a click choosing its row, a color per value of a column, and a list of them. The Value panel shows a geometry on a small map. Copy one as WKT or GeoJSON, or export the rows as GeoJSON. There is no background map: nothing goes to a server outside Nexo.' | transloco }}
  • {{ 'Code, in the SQL editor or in a result tab, writes a whole program that runs the statement in Node.js, Python, Java, C#, Go, Rust, PHP or Ruby with the usual library of its engine, or its command line, with its parameters bound. It reads the connection from the DATABASE_URL environment variable. Copy as string gives the statement alone as a string of that language, and Paste from code turns a string copied from a program back into SQL.' | transloco }}
