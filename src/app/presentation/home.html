NEXO DOCUMENTATION

A workspace that works your way.

One workflow for your desktop and your server. Your collections stay portable.

Send a request

Open the workspace, enter an HTTP URL, choose a method and click Send. Add headers, query parameters, authentication and a body. Inspect the response, headers, cookies and test results below the editor.

Collections and environments

Create a collection or import a portable collection, an environment, OpenAPI, HAR or a cURL command. Save requests into folders. Choose an environment to resolve variables such as {{'{{base_url}}'}}. Export your collection at any time.

Scripts and collection runs

Write JavaScript pre-request and post-response scripts with pm.test, pm.expect and scoped variables. The runner executes collections with iterations and JSON data, records assertions, and supports cancellation. 

pm.test('Successful response', () => {{ '{' }}
  pm.expect(pm.response.code).to.be.within(200, 299);
{{ '}' }});

Protocols and local services

Use the Protocols panel for WebSocket, Socket.IO, MQTT and gRPC. Provide a .proto definition for gRPC. Mocks listen on the machine running the engine; datasets accept JSON and CSV and can be queried with SQL. Git exports live in your Nexo project directory.

Hosting your workspace

The server edition uses account authentication, workspace membership and document revisions. Public pages render on the server; the private workspace is excluded from indexing. In server mode, API requests execute from the server network. In desktop mode, they execute from your computer.
