# Privacy policy · Política de privacidad

_Last updated: 4 November 2026 · Última actualización: 4 de noviembre de 2026_

## English

Nexo API is a desktop application (and an optional local web version) for building and testing APIs. It runs on your computer and does not have accounts.

**What we collect.** Nothing. Nexo API has no analytics, telemetry, advertising or tracking, and it does not send data to the developer or to any third party.

**Data on your computer.** Collections, environments, variables, history and settings are stored in the application's data folder on your computer. Secrets saved in the vault are encrypted with AES-256-GCM, using a key kept in your operating system's credential store. You can delete this data at any time by removing it in the app or uninstalling it.

**Network requests.** Nexo API only connects to the addresses you enter: requests, real-time connections, OAuth token endpoints and MCP servers. What those services receive and keep is governed by their own policies. The local service of the app only listens on this computer (loopback).

**Microsoft Store.** If you install Nexo API from the Microsoft Store, Microsoft may collect installation and diagnostic data under its own privacy statement. The developer does not receive personal information through it.

**Contact.** Questions or requests: <https://github.com/DaftyCode/nexo_api/issues>.

## Español

Nexo API es una aplicación de escritorio (y una versión web local opcional) para crear y probar APIs. Funciona en tu equipo y no tiene cuentas.

**Qué recopilamos.** Nada. Nexo API no tiene analítica, telemetría, publicidad ni seguimiento, y no envía datos al desarrollador ni a terceros.

**Datos en tu equipo.** Las colecciones, entornos, variables, historial y ajustes se guardan en la carpeta de datos de la aplicación en tu equipo. Los secretos del vault se cifran con AES-256-GCM, con una clave guardada en el almacén de credenciales de tu sistema operativo. Puedes borrar estos datos cuando quieras eliminándolos en la app o desinstalándola.

**Peticiones de red.** Nexo API solo se conecta a las direcciones que tú introduces: peticiones, conexiones en tiempo real, endpoints de tokens OAuth y servidores MCP. Lo que esos servicios reciban y conserven se rige por sus propias políticas. El servicio local de la app solo escucha en este equipo (loopback).

**Microsoft Store.** Si instalas Nexo API desde Microsoft Store, Microsoft puede recopilar datos de instalación y diagnóstico según su propia declaración de privacidad. El desarrollador no recibe información personal a través de ella.

**Contacto.** Dudas o solicitudes: <https://github.com/DaftyCode/nexo_api/issues>.
